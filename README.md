# Redis Django RealTime Analytics Async Learning Project
In this project we aimed to implement Redis Capabilities for Online Poll website and its Online Analytics for better Improvement and Performance

## Technologies
- Python
- Django
- Django Ninja
- Redis
- Docker

## Features
- Restful APIs
- Async ORM
- Async Django
- DB data import
- Cookie Handling
- Redis Hash
- Rate limiting by Redis
- Redis Pipeline
- Redis Transaction
- Redis Cache
- Redis List and Set
- TTL invalidation
